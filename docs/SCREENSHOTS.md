All images are captured from the **running application** with an isolated demo workspace and synthetic data, not from the author's production customer records or credentials.

## 01. 团队工作台 / Team dashboard

项目、任务、日历、知识汇总在同一个工作台，而不是多个分散入口。

The dashboard consolidates projects, tasks, calendars and reviewed knowledge.

[![团队工作台](images/01-dashboard.webp)](images/01-dashboard.webp)

## 02. 项目任务 / Project tasks

任务归属项目，分配状态、负责人、验收要求和时间节点；讨论始终挂在任务内。

A task belongs to a project and owns its collaboration history, responsibilities and milestones.

[![项目任务](images/02-project-tasks.webp)](images/02-project-tasks.webp)

## 03. 团队日历 / Shared calendar

跨项目查看期限与会议。进行中任务从今天一直显示到截止日；逾期后不延续高亮。

Across projects, ongoing tasks remain visible from today through their due date.

[![团队日历](images/03-team-calendar.webp)](images/03-team-calendar.webp)

## 04. 知识与记忆 / Knowledge and memory

将原始资料、讨论纪要、已采纳知识和团队公开知识分开管理，保留来源与确认状态。

Original sources, candidate summaries, adopted decisions and published team knowledge remain distinct.

[![知识与记忆](images/04-knowledge-memory.webp)](images/04-knowledge-memory.webp)

## 05. AI 员工 / AI employees

团队层定义专家职责、模型、系统提示词、Skills、MCP 与平台工具，项目内只需显式邀请。

Team-level reusable AI specialist profiles with models, instructions, skills and scoped tools.

[![AI 员工](images/05-ai-employees.webp)](images/05-ai-employees.webp)

## 06. 技能与连接 / Skills and integrations

Skill、平台插件、MCP 和模型厂商分别管理；外部来源导入后需审核，不自动执行。

Manage skills, platform tools, MCP servers and model providers separately. Imported content is reviewed before use.

[![技能与连接](images/06-skills-connectors.webp)](images/06-skills-connectors.webp)

## 07. 任务内共同对话 / Real-time task collaboration

多人查看、实时消息、输入中状态与项目资料并置。AI 工具记录可折叠到对应回复中。

Humans collaborate within the same task, while AI runs are explicitly invoked and remain auditable.

[![任务内多人对话](images/07-task-discussion.webp)](images/07-task-discussion.webp)

## 08. @AI 与 @文件 / Mention an agent or file

输入 @ 后搜索具备访问权限的 Agent 和资料。**只发真人消息不会自动触发模型。**

Mention an authorized agent or a project file. Ordinary human chat does not implicitly trigger model calls.

[![选择 Agent 和资料](images/08-mention-agents.webp)](images/08-mention-agents.webp)

## 09. 项目文件浏览器 / Project file browser

多层文件夹管理、文件预览、来源记录和路径检索。Agent 使用相同的项目资料权限。

Organize nested folders, preview files and search paths. AI uses the same scoped source IDs and permissions.

[![项目文件浏览器](images/09-project-files.webp)](images/09-project-files.webp)
