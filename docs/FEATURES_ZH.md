# 共知功能全览（中文版）

[返回中文首页](../README.md) · [English features](FEATURES_EN.md) · [截图画廊](SCREENSHOTS.md) · [安装指南](DEPLOY_ZH.md)

> 共知的核心产品价值不是“让每个人都能和 AI 聊天”，而是让多人、多角色与 AI 员工的协作过程变成可审核、可持续复用的组织知识。

## 1. 从团队到任务，而不是无归属的聊天

![项目任务界面](images/02-project-tasks.webp)

**团队 / 公司** 是组织容器，拥有成员、项目、AI 员工配置和共享知识。**项目** 管理计划、文件、日历与任务。**任务** 是讨论发生的地方：每条人的消息、AI 回复、文件引用、工具执行、候选任务和成果都有实际任务上下文。

- 管理员可创建、编辑、归档或恢复项目、任务和部分业务对象；
- 任务可以设定状态、负责人、截止日期、验收要求；
- 多人进入同一任务可实时聊天，能看到当前任务的在线成员与正在输入；
- 真人发言与 AI 员工发言按身份区分，自己的消息在右边；
- 聊天不因为有人输入一句话就自动计费：必须明确邀请对应 Agent。

## 2. AI 员工是真正的配置资产

![AI 员工](images/05-ai-employees.webp)

团队级维护 AI 员工，从名称与职责、System Prompt、SOUL.md、AGENTS.md，到模型、Skill、MCP、平台插件和运行预算。项目可复用相同员工配置，同时保持不同项目资料和会话相互隔离。

通过 <code>@员工</code> 激活一轮执行；可以在本次运行里使用安全模式或明确授权的免重复批准模式。**完整授权模式也不是任意命令执行权限**，仍受项目 ACL、允许工具和运行限制约束。

执行 Trace 包含模型步骤、工具调用与返回、已知 token、来源和审核操作。模型的私有思维链不会被伪造成可审查日志。

## 3. 文件夹 + 可引用的项目知识

![项目文件浏览器](images/09-project-files.webp)

项目内有独立的文件管理空间：多层文件夹、上传、重命名、移动、路径查找、版本信息。常见 Markdown、JSON、TXT、Word、Excel、PDF、图片能在浏览器中预览；扫描 PDF 可能无法建立文字检索索引，应明确显示“不支持解析”而不是编造内容。

输入 <code>@文件名称</code> 可搜索当前项目授权文件。Agent 可先查看当前目录和检索结果，再决定是否分段读取大文件，不需要每轮把所有原文注入上下文。

实现使用 SQLite FTS5/BM25 分块全文检索，不将当前能力误称为大型向量知识图谱。

## 4. 知识形成的责任链

![知识与记忆](images/04-knowledge-memory.webp)

典型过程：原件上传 → 有来源的讨论 → 候选纪要/行动项 → 人工确认 → 项目知识 → 明确发布为团队公共快照。

- 原件、摘要、决策、结果不互相覆盖；
- 未确认的纪要和模型建议不会直接变成团队制度；
- 项目记忆有来源、版本、状态和权限；
- 只有明确批准的知识快照才供团队其他项目复用；
- 审核通过的经验可以另行形成 Skill 草稿，Skill 不会仅因生成便自动执行。

这一层不是“模型记住了什么”的幻想，而是用户可以查看和核对的知识流转机制。

## 5. Skills、MCP 与平台插件各司其职

![技能与连接](images/06-skills-connectors.webp)

| 能力 | 用来解决什么问题 |
|---|---|
| **Skill** | 规范方法和输出要求，可包含 SKILL.md 与参考文件 |
| **MCP** | 连接授权的外部服务、文档和数据库，需连接测试与工具白名单 |
| **平台插件** | 按权限在共知内读写日程、任务、知识、文件、项目计划等 |
| **Harness** | 控制模型轮数、工具次数、超时、审批、错误与上下文预算 |
| **模型连接** | 由部署者配置厂商 API、协议、Model ID 和凭证 |

外部 Skill 压缩包可上传预览、从受支持来源读取后作为待审核草稿导入。平台不将没有授权的 MCP 连接显示为“已连通”。

## 6. 首页日历与任务状态

![团队日历](images/03-team-calendar.webp)

任务状态为“进行中”且截止日期在未来时，从**今天到截止日（含当天）**持续高亮；截止之后不再把已经逾期的任务延伸到每天，同时在逾期列表中保留提示。完成、取消、暂停等状态有不同的显示规则；会议跨多日时在起止日期间显示。

工作台自带团队日历，用户无需先进入独立日程页才能查看近期安排。时间按项目时区计算，不依赖管理员浏览器恰好在哪个时区。

## 7. 语音输入只代替打字

聊天和较长文本输入框支持简洁麦克风按钮。用户点击录音，结束后通过服务端对接可选的 SenseVoiceSmall ASR，文字插入**当前输入框**，由用户检查，再自行点击发送或保存。

语音不会自动调用 AI、创建会议或存入知识库。浏览器需要 HTTPS / localhost 和麦克风授权；第三方语音服务仍可能收费、限流或失败。

## 8. 真实能力与尚未实现的愿景

**已实现：** 单 Agent 工具执行与审批、多人任务聊天、知识记录与人工采用、项目文件管理、日程、可选语音、团队复用技能/MCP/模型配置。

**仍在路线图：** 一轮调度多位 Agent 并行工作；AI 与 AI 自动协商；共享计算机与宿主高权限操作；企业级分布式高可用；完整可验证图谱与跨 SaaS 数据同步。暂不宣传为已经可用。

## 9. 最适合谁？

需要把项目管理、资料检索、团队讨论和 AI 执行放到同一入口的小型团队、研究组、培训研发组、产品与技术团队，尤其适合愿意自托管、重视资料来源和可复用操作经验的人。
