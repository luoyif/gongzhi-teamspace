# Contributing

Welcome contributions to verifiable collaborative memory, readable UI, portability and well-scoped agents.

- Keep pull requests focused; explain migration/permissions impact.
- Make clear what was actually tested, what uses fixtures and what is NOT_RUN.
- Never submit private data, tokens, production traces or hidden user information.
- Do not silently retry paid model calls or auto-adopt AI recommendations.
- Retain historical evidence and tool success receipts; preserve tenant isolation.
- Respect TencentCloud/Octop MIT and any third-party Skill/MCP licenses.
